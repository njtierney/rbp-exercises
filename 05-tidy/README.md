# Penguin body mass analysis

Fits a model of penguin body mass against flipper length and species,
for the 2026 report to the department.

## How to run

Open `my-project.Rproj`, then run the scripts in `analysis/` in order:

1. `01-clean-data.R`
2. `02-fit-model.R`
3. `03-make-figures.R`

Figures are written to `output/figures/`.

## Data

`data-raw/penguins-raw.csv` is from the {palmerpenguins} package, saved on
2026-03-14. Do not edit this file. `data/penguins.csv` is produced by
`data-raw/clean-penguins.R`.
